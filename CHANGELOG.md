# Changelog

## 1.0.0

First release.

- Follow my pointer: push past the empty screen edge to move the iPad there, with Light, Medium and Firm push strengths.
- Move the iPad from the menu bar window, with ⌃⌥⌘← / ⌃⌥⌘→, or with `edgewise://move/left`, `edgewise://move/right` and `edgewise://swap`.
- Multiple display support: attaches to the display you pushed against.
- `edgewisectl` command-line helper: `status`, `set`, `backup`, `restore`, `reload`, `dump`.
- Backs up the original Universal Control arrangement on first launch.
- Universal binary; tested on macOS 26.4.
